## Einführung in SQL JOINs und Wiederholung zu DISTINCT

### SQL JOINs

Ein JOIN in SQL wird verwendet, um Daten aus zwei oder mehr Tabellen basierend auf einer verwandten Spalte zwischen ihnen zu kombinieren. Es gibt verschiedene Arten von JOINs, wie INNER JOIN, LEFT JOIN, RIGHT JOIN und FULL JOIN. In dieser Aufgabe verwenden wir einen **INNER JOIN**, um nur die Datensätze zurückzugeben, die in beiden Tabellen übereinstimmende Werte haben.

#### Beispiel für einen INNER JOIN:
```sql
SELECT t1.spalte1, t2.spalte2
FROM tabelle1 AS t1
INNER JOIN tabelle2 AS t2
ON t1.gemeinsame_spalte = t2.gemeinsame_spalte;
```

### SQL DISTINCT

Das Schlüsselwort **DISTINCT** wird verwendet, um doppelte Zeilen aus den Ergebnissen einer Abfrage zu entfernen. Es ist nützlich, wenn Sie nur eindeutige Werte aus einer Spalte oder einer Kombination von Spalten benötigen.

#### Beispiel für DISTINCT:
```sql
SELECT DISTINCT spalte
FROM tabelle;
```

## Bestellte Artikel

### Aufgabenstellung

In der Datenbank gibt es zwei Tabellen: **Products** (enthält Informationen zu den Produkten) und **order_details** (enthält Details zu den Bestellungen). Ihre Aufgabe ist es, eine Liste aller **einzigartigen Produkte** zu erstellen, die bisher bestellt wurden. 

1. Verwenden Sie einen **INNER JOIN** oder erzeugen Sie das kartesische Produkt mit bedingter Restriktion, um die Tabellen **Products** und **order_details** zu verbinden.  
2. Nutzen Sie **DISTINCT**, um sicherzustellen, dass jedes Produkt nur einmal in der Ergebnisliste erscheint.  
3. Geben Sie die Spalten **ProductID** und **ProductName** aus.
