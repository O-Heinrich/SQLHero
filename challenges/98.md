## Einführung in den SQL CREATE TABLE Statement

Mit dem SQL `CREATE TABLE` Statement kann eine neue Tabelle erstellet werden.

### Verwendung des CREATE TABLE Statements

Hier ist die grundlegende Syntax eines `CREATE TABLE` Statements:

```sql
CREATE TABLE tabellenname (
  spalte1 datentyp1,
  spalte2 datentyp2
);
```

### Neue Tabelle aus existierender Tabelle erstellen

Mit dem `CREATE TABLE` Statement kann auch eine Tabelle basierend auf einer bereits exitierenden Tabelle erstellt werden. Die Spaltennamen und Typen werden hierbei übernommen. Durch eine innere `SELECT` Abfrage können die zu kopierenden Datensätze festgelegt bzw. auch gefitlert werden.

```sql
CREATE TABLE tabellenname AS
  SELECT * FROM existing_table
  WHERE bedingung;
```

Weiterführende Informationen finden Sie hier: [w3schools.com](https://www.w3schools.com/sql/sql_create_table.asp)

## Filmarchiv erstellen

> **Aufgabe:**
>
> - Erstellung der Tabelle *filmarchiv* mit ausgewählten Attributen aus der Tabelle *film*.
> - Übertragung aller Datensätze mit Erscheinungsjahr vor 1950 in die neue Tabelle und anschließendes Löschen dieser Datensätze aus der Ursprungstabelle.

### SQL-Operationen

- Tabellen: film, filmarchiv
- Filter: Nur Filme vor dem Jahr 1950

### Wichtige Hinweise

1. Das Attribut Preis wird nicht in die neue Tabelle übernommen.
2. Es wird keine Ausgabe erwartet.
3. Eventuell werden hier mehrere Befehle benötigt. Ein Semikolon am Ende eines Befehls ist hierfür Pflicht.
