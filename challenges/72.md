query: |
  SELECT AVG(klassentabelle.gesamt) FROM ( 
    SELECT k.name AS name, SUM(u.stunden) AS gesamt FROM klasse k 
    JOIN unterricht u ON k.id = u.klasse_id 
    GROUP BY k.name 
    UNION SELECT k.name AS name, 0 AS gesamt FROM klasse k 
    LEFT JOIN unterricht u ON k.id = u.klasse_id 
    WHERE u.klasse_id IS NULL 
  ) AS klassentabelle;
---

## Durschnittliche Unterrichtsstunden

Wieviele Stunden Unterricht haben die Klassen durchschnittlich? 

**Hinweis:** Als innere Tabelle hat man eine Liste der Klassen mit ihrer Stundenzahl. In dieser muss man ein `UNION` verwenden, damit die 8D, die gar keinen Unterricht hat, mitgezählt wird.

### Ausgabe

| avg                |
| :----------------- |
| 7.7500000000000000 |
