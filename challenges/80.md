query: |
  SELECT 
    ustunden.name AS "Name", 
    ustunden.anzahl + agstunden.anzahl AS "Anzahl" 
  FROM ( 
    SELECT 
      l.name AS name, 
      SUM(u.stunden) AS anzahl 
    FROM 
      lehrer l, 
      unterricht u 
    WHERE 
      l.id = u.lehrer_id 
    GROUP 
      BY l.name 
  ) AS ustunden, ( 
    SELECT 
      l.name AS name, 
      COUNT(*) AS anzahl 
    FROM 
      lehrer l, 
      ag a 
    WHERE 
      l.id = a.lehrer_id 
    GROUP BY 
      l.name 
  ) AS agstunden 
  WHERE 
    ustunden.name = agstunden.name
  ORDER BY 2 DESC;

## Arbeitsstunden der Lehrer

Es soll eine Liste erstellt werden, aus der hervorgeht, wie viele Stunden jeder Lehrer arbeitet! Dabei zählen die Unterrichtsstunden normal und jede AG, die ein Lehrer leitet, zählt 1 Stunde. Dabei soll die Ausgabe nach Stunden absteigend sortiert sein.

### Ausgabe

| Name         | Anzahl |
|--------------|-------:|
| Zimmermann   |     11 |
| Amann        |      7 |
| Buttermüller |      6 |
