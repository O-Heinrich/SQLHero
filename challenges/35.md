query: |
  SELECT Mitarbeiter_ID, Name 
  FROM mitarbeiter 
  WHERE Gehaltgruppe < (
    SELECT Gehaltgruppe FROM mitarbeiter WHERE Name= 'Laufer'
  );
---

## Mitarbeiter Where-Klausel

Selektieren Sie Mitarbeiter, die mehr als die Kollegin „Laufer“ verdienen. Nutzen Sie dabei eine Unterabfrage.

### Ausgabe

|mitarbeiter_id|  name  |
|--------------|--------|
|      1       | Hansen |
|      2       |Knudsen |
|      4       | Kaiser |
|      5       |Paulsen |
