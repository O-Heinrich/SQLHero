## Einführung in verschachtelte Abfragen

Eine SQL-Abfrage kann in einer anderen SQL-Abfrage verschachtelt sein, um den Rückgabewert der inneren Abfrage weiter zu verwenden.

### Beispielhafte Verwendung verschachtelter Abfragen in der WHERE Klausel

Eine Möglichkeit, verschachelte Abfragen zu Nutzen, ist in der WHERE Klausel:

```sql
SELECT * FROM tabelle1
WHERE spalte1 = (
  SELECT MAX(spalte2) FROM tabelle2
);
```

Diese Abfrage gibt Zeilen aus `tabelle1` aus, für welche `spalte1` gleich dem maximum von `spalte2` der `tabelle2` sind.

In diesem Fall darf die innere Abfrage nur einen einzelnen Wert zurückgeben, ansonsten führt dies zu einem Fehler. Es gibt aber auch weitere Anwendungsmöglichkeiten von verschachtelten Abfragen.

Verschachtelte Abfragen können nicht nur in der `WHERE` Klausel sondern zum Beispiel auch direkt im `SELECT` oder `FROM` eingesetzt werden, um Tabellen, Spalten oder Werte zu ersetzen.

Weiterführende Informationen finden Sie hier: [geeksforgeeks.org](https://www.geeksforgeeks.org/sql/nested-queries-in-sql/)
