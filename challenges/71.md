query: |
  SELECT deutsch.klasse AS klasse, deutsch.stunden AS deutsch, geschichte.stunden AS geschichte 
  FROM ( 
    SELECT k.name AS klasse, SUM(u.stunden
  ) AS stunden FROM klasse k 
   JOIN unterricht u ON k.id = u.klasse_id WHERE u.fach = 'deutsch' GROUP BY k.name) AS deutsch ,  ( SELECT k.name AS klasse, SUM(u.stunden) AS stunden FROM klasse k JOIN unterricht u ON k.id = u.klasse_id WHERE u.fach = 'geschichte' GROUP BY k.name ) AS geschichte  WHERE geschichte.klasse = deutsch.klasse
---

## Klassen mit Fächern

Eine Liste aller Klassen, in der für jede Klasse vermerkt ist, wie viele Stunden Geschichte und wie viele Stunden Deutsch sie hat. (D.h. 3 Spalten). Hinweis: Es gibt eine innere Abfrage für Deutsch und eine für Geschichte.
