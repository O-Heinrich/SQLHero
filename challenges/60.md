query: |
  SELECT 
    k.name, 
    SUM(u.stunden) AS anzahl 
  FROM 
    klasse k 
  JOIN 
    unterricht u 
  ON 
    k.id = u.klasse_id 
  GROUP BY
    k.name
  ORDER BY anzahl DESC LIMIT 1;

## Einführung in die SQL LIMIT Klausel

Die SQL `LIMIT` Klausel wird verwendet, um die Anzahl der ausgegebenen Datensätze zu limitieren.

### Verwendung der LIMIT Klausel

Folgendes ist die grundlegende Nutzung der `LIKE` Klausel:

```sql
SELECT * FROM tabelle
LIMIT 10;
```

Weiterführende Informationen finden Sie hier: [w3schools.com](https://www.w3schools.com/sql/sql_top.asp)

## Meiste Unterrichtsstunden

Die Klasse, die am meisten Unterricht hat; mit der Anzahl der Unterrichtsstunden. Man addiert für jede Klasse die Unterrichtsstunden, sortiert dann nach der Stundenzahl absteigend, und führt dann `LIMIT 1` aus, um nur die erste Zeile zu bekommen.

### Ausgabe

| name | anzahl |
| :--- | :----- |
| 8C   | 13     |
