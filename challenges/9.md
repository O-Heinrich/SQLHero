## Wiederholung von SQL JOINs

### SQL JOINs

Ein **JOIN** in SQL wird verwendet, um Daten aus zwei oder mehr Tabellen basierend auf einer verwandten Spalte zwischen ihnen zu kombinieren. In dieser Aufgabe verwenden wir einen **INNER JOIN**, um nur die Datensätze zurückzugeben, die in beiden Tabellen übereinstimmende Werte haben.

#### Beispiel für einen INNER JOIN:
```sql
SELECT t1.spalte1, t2.spalte2
FROM tabelle1 AS t1
INNER JOIN tabelle2 AS t2
ON t1.gemeinsame_spalte = t2.gemeinsame_spalte;
```

### Kartesisches Produkt

Das **kartesische Produkt** (auch als CROSS JOIN bekannt) ist eine Operation, die jede Zeile der ersten Tabelle mit jeder Zeile der zweiten Tabelle kombiniert. Dies führt zu einer Ergebnismenge, die die Anzahl der Zeilen in der ersten Tabelle multipliziert mit der Anzahl der Zeilen in der zweiten Tabelle enthält.

#### Beispiel für ein kartesisches Produkt:
```sql
SELECT t1.spalte1, t2.spalte2
FROM tabelle1 AS t1, tabelle2 AS t2;
```

### Warum ist das kartesische Produkt eine valide Lösung?

Das kartesische Produkt kann in bestimmten Fällen eine valide Lösung sein, insbesondere wenn Sie alle möglichen Kombinationen von Zeilen aus zwei Tabellen benötigen. In dieser Aufgabe könnte das kartesische Produkt verwendet werden, um alle Kombinationen von Lieferanten und Produkten zu erhalten, und dann die gewünschten Zeilen mit einer WHERE-Klausel zu filtern.

## Artikel der Firma

### Aufgabenstellung

Welche Artikel liefert die Firma **„Norske Meierier“**? Erstellen Sie eine Liste der Artikel, die von dieser Firma geliefert werden, und sortieren Sie die Liste **alphabetisch aufsteigend** nach der Artikelbezeichnung.

#### Schritte zur Lösung:
1. Verwenden Sie einen **INNER JOIN** oder einen **CROSS JOIN**, um die Tabellen `products` und `suppliers` zu verbinden. Die Verbindung erfolgt über die Spalte `SupplierID`.
2. Filtern Sie die Ergebnisse, um nur die Artikel der Firma **„Norske Meierier“** anzuzeigen.
3. Sortieren Sie die Ergebnisse nach der Artikelbezeichnung (`ProductName`) in aufsteigender Reihenfolge.

#### Erwartete Ausgabe

Die Ausgabe sollte eine Tabelle mit den folgenden Spalten enthalten:

| CompanyName     | ProductName      |
| :-------------- | :--------------- |
| Norske Meierier | Flotemysost      |
| Norske Meierier | Geitost          |
| Norske Meierier | Gudbrandsdalsost |

#### Hinweise:
- Die Verwendung eines **INNER JOIN** ist in der Regel klarer und besser lesbar als ein kartesisches Produkt mit einer WHERE-Klausel.
- Moderne Datenbank-Engines optimieren beide Ansätze oft gleich, sodass es **keinen signifikanten Leistungsunterschied** gibt.
- Ein kartesisches Produkt **ohne WHERE-Klausel** sollte vermieden werden, da es eine sehr große Ergebnismenge erzeugt und ineffizient ist.
