## Einführung in den SQL IN Operator

Der SQL `IN` Operator kann in `WHERE` Klauseln verwendet werden, um auf einen von mehreren Werten zu filtern.

### Verwendung des IN Operators

Folgendes ist die grundlegende Nutzung des `IN` Operators:

```sql
SELECT * FROM tabelle
WHERE spalte IN (wert1, wert2);
```

Dies ist equivalent zu folgender Abfrage:

```sql
SELECT * FROM tabelle
WHERE spalte = wert1 OR spalte = wert2;
```

Weiterführende Informationen finden Sie hier: [w3schools.com](https://www.w3schools.com/sql/sql_in.asp)
