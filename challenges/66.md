  LEFT JOIN klasse k ON s.klasse_id = k.id;

## Liste aller Schüler mit Klasse

Eine Liste ALLER Schüler, aus der hervorgeht, in welcher Klasse sie jeweils sind. Auch Schüler ohne Klasse (z.B. Wiesenhoff) sollen aufgeführt werden.

> **Tipp:** `LEFT JOIN` oder `RIGHT JOIN`

### Ausgabe

| Nachname      | Vorname   | Klasse |
| :------------ | :-------- | :----- |
| Schmidt       | Michael   | 8A     |
| Ebert         | Anne      | 8B     |
| Meier         | Johannes  | 8B     |
| Schwarzmüller | Maria     | 8C     |
| Wiesenhoff    | Christian | NULL   |
| Zimmermann    | Anne      | NULL   |
