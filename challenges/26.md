## Einführung in den SQL LIKE Operator

Der SQL `LIKE` Operator kann in `WHERE` Klauseln verwendet werden, um textuelle Werte auf ein Muster zu Filtern.

### Verwendung des LIKE Operators

Folgendes ist die grundlegende Nutzung des `LIKE` Operators:

```sql
SELECT * FROM tabelle
WHERE spalte LIKE muster;
```

Das `muster` ist hier ein String, welcher Wildcards enthalten kann. Zum Beispiel steht ein `%` für beliebig viele beliebige Zeichen.  
Wenn `muster` also z. B. '%z' bedeutet dass, alle Zeichenketten, welche auf 'z' enden.

Weiterführende Informationen finden Sie hier: [w3schools.com](https://www.w3schools.com/sql/sql_like.asp)
