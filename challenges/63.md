query: |
  SELECT l.name, l.vorname 
  FROM lehrer l 
  JOIN unterricht u ON l.id = u.lehrer_id 
  JOIN klasse k ON u.klasse_id = k.id 
  JOIN schueler s ON k.id = s.klasse_id 
  WHERE s.name = 'Schmidt' 
  UNION SELECT l.name, l.vorname 
  FROM lehrer l 
  JOIN klasse k ON l.id = k.klassenlehrer_id 
  JOIN schueler s ON k.id = s.klasse_id 
  WHERE s.name = 'Schmidt'
  ORDER BY name;

## Einführung in den SQL UNION Operator

Der SQL `UNION` Operator kombiniert die Ergebnisse mehrerer `SELECT` Abfragen und fitlert Duplikate.

### Verwendung des UNION Operators

Folgendes ist die grundlegende Nutzung des `UNION` Operators:

```sql
SELECT spalte FROM tabelle1
UNION
SELECT spalte FROM tabelle2;
```

Weiterführende Informationen finden Sie hier: [w3schools.com](https://www.w3schools.com/sql/sql_union.asp)
