query: |
  SELECT SUM(od."Quantity") AS "Stückzahl",  
       c."CategoryName" AS "Kategorie"  
  FROM order_details AS od,  
      products AS p,  
      categories AS c  
  WHERE od."ProductID" = p."ProductID"  
    AND p."CategoryID" = c."CategoryID"  
  GROUP BY c."CategoryName"  
  ORDER BY c."CategoryName";

## Stückzahlen bestellter Artikel

Es sollen pro Kategorien die Stückzahlen der bestellten Artikel ausgegeben werden.

- Ermittlung der Gesamtstückzahlen bestellter Artikel pro Kategorie  
- Alphabetische Sortierung nach Kategorienamen  

### SQL-Operationen

- `SUM()`: Summierung der Bestellmengen pro Kategorie
- `GROUP BY`: Gruppierung nach Kategorienamen
- Tabellen: order_details, products, categories
- Filter: od."ProductID" = p."ProductID" AND p."CategoryID" = c."CategoryID"
- Sortierung: Alphabetisch nach Kategorienamen (`c."CategoryName"`)

### Ausgabe

| Stückzahl | Kategorie      |
|----------:|:---------------|
|      9532 | Beverages      |
|      5298 | Condiments     |
|      7906 | Confections    |
|      9149 | Dairy Products |
|      4562 | Grains/Cereals |
|      4199 | Meat/Poultry   |
|      2990 | Produce        |
|      7681 | Seafood        |

### Wichtige Hinweise  

1. Verknüpfung von drei Tabellen über Produkt- und Kategorie-IDs
2. Summierung aller Bestellmengen (`Quantity`) pro Produktkategorie
3. Alphabetische Anordnung der Kategorien für bessere Übersichtlichkeit
