query: |
  SELECT r.nummer AS raum,
       COALESCE(d.stunden, 0) AS "Deutsch Stunden",
       COALESCE(e.stunden, 0) AS "Englisch Stunden"
  FROM raum r
  LEFT JOIN (
      SELECT u.raum_id, SUM(u.stunden) AS stunden
      FROM unterricht u
      WHERE u.fach = 'Deutsch'
      GROUP BY u.raum_id
  ) d ON r.id = d.raum_id
  LEFT JOIN (
      SELECT u.raum_id, SUM(u.stunden) AS stunden
      FROM unterricht u
      WHERE u.fach = 'Englisch'
      GROUP BY u.raum_id
  ) e ON r.id = e.raum_id
  ORDER BY r.nummer;

## Räume mit Deutschunterricht 2

Erstellen Sie eine Liste, in der alle Räume aufgeführt sind. Zu jedem Raum soll angegeben werden:
- Wie viele Stunden Deutsch dort unterrichtet wird
- Wie viele Stunden Englisch dort unterrichtet wird

> **Hinweis:** Diese Aufgabe erfordert 2 innere Abfragen (Subqueries).

| :--------- | --------------: | ---------------: |

| R110       |               0 |                0 |

| R203       |               4 |                0 |

| R208       |               0 |                0 |
