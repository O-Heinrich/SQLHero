query: |
  SELECT r.nummer AS raum,
       COALESCE(d.stunden, 0) AS "Deutsch Stunden",
       COALESCE(e.stunden, 0) AS "Englisch Stunden"
  FROM raum r
  LEFT JOIN (
      SELECT u.raum_id, SUM(u.stunden) AS stunden
      FROM unterricht u
      WHERE u.fach = 'Deutsch'
      GROUP BY u.raum_id
  ) d ON r.id = d.raum_id
  LEFT JOIN (
      SELECT u.raum_id, SUM(u.stunden) AS stunden
      FROM unterricht u
      WHERE u.fach = 'Englisch'
      GROUP BY u.raum_id
  ) e ON r.id = e.raum_id
  ORDER BY r.nummer;

## Räume mit Deutschunterricht 2

Eine Liste, in der alle Räume aufgeführt sind. Zu jedem Raum soll in einer Spalte angegeben werden, wie viele Stunden Deutsch dort unterrichtet wird und in einer zweiten Spalte, wie viele Stunden Englisch. Hinweis: 2 innere Abfragen.

| raum       | deutsch_stunden | englisch_stunden |
| :--------- | :-------------: | :--------------: |
| R101       | 0               | 0                |
| R110       | 0               | 0                |
| R112       | 4               | 4                |
| R203       | 4               | 0                |
| R205       | 4               | 0                |
| R208       | 0               | 0                |
| R306       | 0               | 0                |
| Sporthalle | 0               | 0                |
