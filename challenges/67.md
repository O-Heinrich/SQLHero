query: |
  SELECT s.name, SUM(u.stunden) AS anzahl FROM schueler s 
  JOIN unterricht u ON s.klasse_id = u.klasse_id 
  GROUP BY s.name UNION SELECT s.name, 0 AS anzahl FROM schueler s 
  LEFT JOIN unterricht u ON s.klasse_id = u.klasse_id 
  WHERE u.klasse_id IS NULL;
---

## Liste aller Schüler mit Unterricht

Eine Liste ALLER Schüler, in der steht, wieviel Unterricht sie haben. Für die Schüler Zimmermann und Wiesenhoff soll in dieser Übersicht als Stundenzahl '0' erscheinen.

### Ausgabe

| name          | anzahl |
| :------------ | :----- |
| Zimmermann    | 0      |
| Meier         | 7      |
| Schmidt       | 11     |
| Wiesenhoff    | 0      |
| Schwarzmüller | 13     |
| Ebert         | 7      |
