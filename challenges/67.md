query: |
  SELECT s.name, SUM(u.stunden) AS anzahl FROM schueler s 
  JOIN unterricht u ON s.klasse_id = u.klasse_id 
  GROUP BY s.name UNION SELECT s.name, 0 AS anzahl FROM schueler s 
  LEFT JOIN unterricht u ON s.klasse_id = u.klasse_id 
  WHERE u.klasse_id IS NULL
  ORDER BY anzahl DESC, name;

## Liste aller Schüler mit Unterricht

Eine Liste ALLER Schüler, in der steht, wieviel Unterricht sie haben. Für die Schüler Zimmermann und Wiesenhoff soll in dieser Übersicht als Stundenzahl '0' erscheinen. Sortieren Sie das Ergebnis nach `anzahl` absteigend und Name.

### Ausgabe

| name          | anzahl |
| :------------ | -----: |
| Schwarzmüller | 13     |
| Schmidt       | 11     |
| Ebert         | 7      |
| Meier         | 7      |
| Wiesenhoff    | 0      |
| Zimmermann    | 0      |
