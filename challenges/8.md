## Geburtstagsliste

### Aufgabenstellung

Erstellen Sie eine **Geburtstagsliste** der Mitarbeiter, die die folgenden Informationen enthält:
- **Geburtsdatum** (`BirthDate`)
- **Vorname** (`FirstName`)
- **Nachname** (`LastName`)

Die Liste soll **alphabetisch aufsteigend** nach dem Vornamen der Mitarbeiter sortiert sein.

#### Schritte zur Lösung:
1. Wählen Sie die Spalten `BirthDate`, `FirstName` und `LastName` aus der Tabelle `employees` aus.
2. Sortieren Sie die Ergebnisse nach `FirstName` in aufsteigender Reihenfolge.

#### Erwartete Ausgabe

Die Ausgabe sollte eine Tabelle mit den folgenden Spalten enthalten:

| BirthDate                | FirstName | LastName  |
| :----------------------- | :-------- | :-------- |
| 1952-02-19T00:00:00.000Z | Andrew    | Fuller    |
| 1966-01-27T00:00:00.000Z | Anne      | Dodsworth |
| 1963-08-30T00:00:00.000Z | Janet     | Leverling |
| 1958-01-09T00:00:00.000Z | Laura     | Callahan  |
| 1937-09-19T00:00:00.000Z | Margaret  | Peacock   |
| 1963-07-02T00:00:00.000Z | Michael   | Suyama    |
| 1948-12-08T00:00:00.000Z | Nancy     | Davolio   |
| 1960-05-29T00:00:00.000Z | Robert    | King      |
| 1955-03-04T00:00:00.000Z | Steven    | Buchanan  |

#### Hinweise:
- Achten Sie darauf, dass die Spaltennamen korrekt sind und die Großschreibung beachtet wird, da die Datenbank case-sensitive sein könnte.
- Das Geburtsdatum wird im ISO-8601-Format (`YYYY-MM-DDTHH:mm:ss.sssZ`) angezeigt.
