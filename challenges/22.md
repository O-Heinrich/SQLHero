## Einführung in die SQL HAVING Klausel

Die SQL `HAVING` Klausel dient ähnlich wie die `WHERE` Klausel zur Filterung von Datensätzen. Im Gegensatz zur `WHERE` Klausel kann `HAVING` jedoch verwendet werden, um auch Ergebnisse von Aggregatfunktionen zu filtern.

### Verwendung der HAVING Klausel

Die Syntax der `HAVING` Klausel ist grundlegend dieselbe wie die der `WHERE` Klausel.

Hier ist die grundlegende Syntax einer `SELECT` Abfrage mit der `HAVING` Klausel:

```sql
SELECT COUNT(*), spalte FROM tabelle
GROUP BY spalte
HAVING bedingung;
```

Die `bedingung` darf hier auch das Ergebniss der `COUNT` Funktion enthalten. Also z. B. `COUNT(*) > 5`

Weiterführende Informationen finden Sie hier: [w3schools.com](https://www.w3schools.com/sql/sql_having.asp)
