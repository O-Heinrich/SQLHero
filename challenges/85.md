## Einführung in die PostgreSQL TO_CHAR Funktion

Wenn ein Datum oder eine Uhrzeit ausgegeben wird, ist das Format oft nicht automatisch das gewünschte Format. Mit der `TO_CHAR` Funktion, welche nicht zum SQL-Standard gehört aber in vielen SQL-Datenbanken vorhanden ist, kann ein Zeitdatentyp in einen formatierten String umgewandelt werden.

### Verwendung der TO_CHAR Funktion

Hier ist die grundlegende Syntax einer `SELECT` Abfrage mit der `TO_CHAR` Funktion:

```sql
SELECT TO_CHAR(spalte, 'DD.MM.YYYY') FROM tabelle;
```

Der String 'DD.MM.YYYY' gibt an, wie die formatierung als String aussehen soll, in diesem Fall Tag, Monat und Jahr getrennt mit  Punkten.

Weiterführende Informationen finden Sie hier: [postgresql.org/docs](https://www.postgresql.org/docs/current/functions-formatting.html)

## Patienten nach Geburtsdatum sortieren

> **Aufgabe:**
>
> - Ausgabe aller Patienten mit Name, Vorname und formatiertem Geburtsdatum.
> - Sortierung nach Geburtsdatum (absteigend), anschließend nach Name und Vorname (jeweils absteigend).

### SQL-Operationen

- Tabellen: patient
- Sortierung: Pat_GebDatum, Pat_Name, Pat_Vorname (alle absteigend)

### Ausgabe

| Name    | Vorname  | Geburtsdatum |
| :------ | :------- | :----------- |
| Hövel   | Ekkehard | 26.03.2025   |
| Ruppert | Danuta   | 23.03.2025   |
| Hövel   | Elfi     | 25.01.2025   |
| ...     | ...      | ...          |

### Wichtige Hinweise

1. Das Geburtsdatum wird als Zeichenkette im Format TT.MM.JJJJ dargestellt.
