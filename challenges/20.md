query: |
  SELECT 
    c."CategoryName", 
    SUM(p."UnitsInStock" - p."ReorderLevel") AS "Netto-Lagerbestand"
  FROM categories AS c
  INNER JOIN products AS p ON c."CategoryID" = p."CategoryID"
  GROUP BY c."CategoryName"
  ORDER BY "Netto-Lagerbestand";
---

## Netto-Lagerbestand je Kategorie

### Aufgabenstellung

Es soll der **Netto-Lagerbestand** je Kategorie berechnet werden. Der Netto-Lagerbestand ergibt sich aus der Differenz zwischen dem aktuellen Lagerbestand (`UnitsInStock`) und dem Mindestbestand (`ReorderLevel`) aller Produkte einer Kategorie.

> **Hinweis:** Negative Werte bedeuten, dass in dieser Kategorie insgesamt mehr Produkte unter ihrem Mindestbestand liegen als darüber – es besteht also Nachbestellbedarf.

#### Ausgabe

| CategoryName | Netto-Lagerbestand |
|--------------|-------------------|
| Produce | 75 |
| Meat/Poultry | 135 |
| Grains/Cereals | 153 |
| Confections | 221 |
| Dairy Products | 283 |
| Beverages | 364 |
| Condiments | 372 |
| Seafood | 556 |
