query: |
  SELECT 
    v.Name, 
    ' ist Vorgesetzter von ' AS " ", 
    m.Name 
  FROM 
    mitarbeiter v, 
    mitarbeiter m 
  WHERE 
    m.Vorgesetzten_ID = v.Mitarbeiter_ID;

## Mitarbeiter von „Controlling“

Selektieren Sie den Mitarbeiternamen und den Vorgesetztennamen, sodass in einer Zeile folgender Text steht: „XX ist Vorgesetzter von YY“ (z.B. „Paulsen ist Vorgesetzter von König“). Nutzen sie dabei einen Self-Join. 

### Ausgabe

| name  |                    |  name  |
|-------|--------------------|--------|
|Knudsen|ist Vorgesetzter von|Knudsen |
|Laufer |ist Vorgesetzter von| Laufer |
|Kaiser |ist Vorgesetzter von| Kaiser |
|Paulsen|ist Vorgesetzter von|Paulsen |
| König |ist Vorgesetzter von| König  |
